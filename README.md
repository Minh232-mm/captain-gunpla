# CAPTAIN GUNPLA V3 | GITHUB PAGES READY

Website HTML/CSS/JS tĩnh, phong cách dark red mecha / Gunpla. Đã tối ưu desktop, tablet, mobile, gallery vuốt/kéo ngang, chi tiết sản phẩm nhiều ảnh, danh mục, tìm kiếm, sắp xếp, form chuyển sang Zalo (sao chép nội dung yêu cầu, không tự gửi tin).

**Mở `index.html` để xem. Mở `admin.html` để quản lý sản phẩm và xuất lại `products.js`.**
